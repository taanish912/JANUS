# JANUS v18 Pilot Release

Exploratory controlled pilot of goal-conditioned framing in language-model decision support.

- 8 scenarios across 8 domains; 16 paired responses.
- Configured model: adaption / deepseek-v4-flash.
- Corrected paired evaluations: v2; codebook: v1.4.
- 44 claim-level adjudications from an assistant-assisted review workflow.
- The pilot is exploratory, not confirmatory; the 140-word target was not met.
- MED_17 condition mapping correction is documented in v2.
